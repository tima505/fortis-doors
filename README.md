# ФОРТИС — лендинг дверей и распашных ворот

Одностраничный лендинг: каталог из 20 моделей (обычная линия и VIP-серия),
карточка товара, блок гарантий и контакты. Тёмная тема, адаптив под телефон.

## Структура

| Файл | Назначение |
|---|---|
| `Лендинг Двери.dc.html` | **исходник.** Его открывают и правят в дизайн-канвасе |
| `index.html` | то, что отдаётся на GitHub Pages — точная копия исходника |
| `support.js`, `image-slot.js` | рантайм канваса, нужны обоим файлам |

`index.html` — копия, а не симлинк. **После правок в `.dc.html` копию нужно обновить:**

```sh
cp "Лендинг Двери.dc.html" index.html
```

## Адаптив

Два брейкпоинта в блоке `<style>`:

- **≤900px** — шапка в две строки, все сетки в одну колонку, отступы 110px → 74px
- **≤480px** — отступы 16px, каталог в одну колонку, карточка товара становится шторкой снизу

Сетки заданы через `minmax(0, 1fr)` осознанно: исходные `minmax(440px, 1fr)`
не сужались ниже своего минимума, а `image-slot` объявляет `aspect-ratio: 3/2`,
из-за чего min-content ячейки равен высоте × 1.5. Без `min-width: 0` на элементах
сеток обе вещи выталкивали контент за экран.
